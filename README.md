# ⚔️ Fight Simulator

A turn-based browser fight game built with HTML, CSS, and JavaScript.

## 🔗 Live Demo
[Play Fight Simulator](https://ioana2803.github.io/fight-simulator/)

## 🎮 How It Works
- Two fighters face off: **Kiki** (Player 1) vs **Mario** (Player 2)
- Each round, both players roll a **lucky number** — the higher one attacks first
- **Attack** and **Defense** values are randomly generated each round (0 to their max stat)
- If attack > defense, the difference is subtracted from the defender's HP
- The game continues round by round until one fighter reaches 0 HP

## ⚙️ Fighter Stats
| Stat | Player 1 (Kiki) | Player 2 (Mario) |
|------|----------------|-----------------|
| ⚔️ Attack | 13 | 9 |
| 🛡️ Defense | 10 | 10 |
| ❤️ HP | 20 | 25 |

## ✨ Features
- Round-by-round combat log displayed after each round
- Initiative system determines attack order
- Randomized attack and defense rolls each round
- Fighter artwork with animated arena background
- It does not have for now the game over dysplay, but it will be added

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
